# Day 04 — Constraint-Aware Portfolio Optimisation

## Scope
CVXPY mean-variance optimization at asset-class level. It proposes weights and
trade deltas only; it never executes orders. Expected returns and covariance
are supplied inputs, not forecasts generated by this module.

## Objective
Maximise expected return minus risk-aversion-weighted variance and a linear
transaction-cost penalty.

## Constraints
- Fully invested, long-only portfolio.
- Configurable asset minimum and maximum weights.
- Maximum total turnover and per-asset trade size.
- Optional per-asset liquidity limits.
- Post-solver validation of all constraints.

## Install and test
```powershell
pip install cvxpy
pytest tests/test_optimizer.py -v
```

## Limitations
This initial model operates on asset classes, not individual securities or tax
lots. Transaction costs are a configurable linear basis-point approximation.
Parameters are illustrative and require calibration and approval before use.
