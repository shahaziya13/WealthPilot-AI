## Day 06 — Explainability Engine

WealthPilot now generates evidence-grounded explanations for clients, advisors,
and compliance reviewers from supplied drift, risk, tax, trigger, and proposed-trade
data. It emits JSON and Markdown demo reports with a SHA-256 evidence fingerprint.
This layer does not execute trades or provide financial advice. SHAP/LIME are
planned for a later validated XAI stage. Demo inputs are synthetic.
